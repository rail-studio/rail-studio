# Confidential reports / Signalements confidentiels

Email **komagoma.infos@gmail.com** for a suspected security problem or a report
that cannot be shared publicly. Start with the RAIL build, Windows version and
a short description. **Do not attach a screenplay, credentials or memory dump
to your first message.** Do not publish exploitation details in a public issue.

Ecrire a **komagoma.infos@gmail.com** pour un probleme de securite ou confidentiel.
Commencer par le build RAIL, Windows et une description courte. **Ne pas joindre
de scenario, identifiant secret ou dump memoire au premier message.** Ne pas
publier les details d'exploitation dans un ticket public.

KOMAGOMA may request limited evidence privately. Email uses Gmail, a third-party
service; it is not an anonymous or guaranteed end-to-end encrypted drop box.
Only send material you are authorized to share. Sensitive attachments are kept
private by KOMAGOMA and deleted after diagnosis; nothing is published without
agreement. You may ask for deletion using the same contact.

KOMAGOMA pourra demander des elements limites en prive. Gmail est un service tiers,
pas un depot anonyme ni une garantie de chiffrement de bout en bout. Ne transmettre
que ce que vous etes autorise a partager. KOMAGOMA conserve les pieces sensibles
en prive et les supprime apres diagnostic ; aucune publication sans accord.
Vous pouvez demander leur suppression a la meme adresse.

There is no bug-bounty program or response-time guarantee. The public beta is not
released yet; supported versions will be identified when releases are published.

Il n'existe ni programme de prime ni garantie de delai. La beta publique n'est pas
encore sortie ; les versions prises en charge seront precisees a leur publication.
