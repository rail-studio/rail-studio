# Reporting and discussion guidelines / Participer

## Bugs

Use the English or French issue form. One reproducible problem per issue is easier
to investigate. Include the exact build, Windows version, numbered steps and both
expected and actual behavior. State whether addons were enabled. Do not overwrite
your only project copy to reproduce a problem.

Utiliser le formulaire anglais ou francais, avec un probleme par ticket. Indiquer
le build exact, Windows, les etapes et les deux resultats. Preciser les addons
actifs. Ne pas ecraser votre seule copie de projet pour reproduire un probleme.

## Questions and suggestions / Questions et suggestions

Use Discussions: **Questions** for help, **Suggestions** for ideas and concrete
use cases. **Announcements** contains publisher updates. Describe the problem you
want to solve rather than assuming a proposed feature is already planned.

Dans Discussions : **Questions** pour l'aide, **Suggestions** pour les idees et
leurs usages, **Announcements** pour les informations de l'editeur. Une suggestion
ne constitue pas un engagement de developpement.

## Triage

KOMAGOMA reviews reports and uses these labels:

| Label | Meaning / Sens |
| --- | --- |
| needs-information | More reproduction information needed / Informations manquantes |
| confirmed | Reproduced or supported by evidence / Confirme |
| regression | Previously working behavior broke / Regression |
| blocker | Startup, data loss or release-critical failure / Probleme bloquant |
| duplicate | Existing report linked / Doublon lie au ticket existant |
| resolved | Resolution recorded / Resolution documentee |

Labels are assigned after review, not proof of a fix or a response deadline.
Be respectful, stay on topic and never publish another person's private data.

Les labels suivent l'examen du retour, sans garantir un correctif ou un delai.
Rester respectueux, dans le sujet, et ne jamais publier les donnees privees d'autrui.

## Private source / Code prive

This repository is for reports and discussions. It does not accept changes to the
private application source. Do not paste proprietary project or third-party code.

Ce depot recoit les retours et discussions, pas les modifications du code applicatif
prive. Ne pas publier de contenu de projet ou de code tiers confidentiel.
